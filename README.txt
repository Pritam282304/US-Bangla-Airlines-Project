US-Bangla Airlines Front Page
==============================

Project Type:
Simple Webpage Project (KSA-02)

Technologies:
- HTML5
- CSS3
- JavaScript

Main Features:
1. Airline-style navigation bar
2. Hero banner
3. Flight booking interface
4. Interactive booking tabs
5. Destination swap button
6. Promo code interaction
7. Search flight notification
8. Sky Star loyalty section
9. Responsive/mobile layout
10. Toast notification messages

How to Run:
1. Keep all files and the assets folder in the same project directory.
2. Open index.html in a web browser.
3. For the best development experience, open the folder in VS Code and use Live Server.

Files:
- index.html  -> webpage structure
- style.css   -> design and responsive layout
- script.js   -> interactive functions
- assets/     -> logo and hero image

Note:
This is a student demonstration project inspired by the layout and functionality of an airline booking homepage. It is not an official US-Bangla Airlines website and does not provide real flight booking services.
